Five AI capabilities on satellite & LiDAR data

Upload a satellite image or LiDAR scan and get instant AI-powered analysis. Built on Sentinel-2 imagery (EuroSAT benchmark, F1 = 0.99) with PyTorch models deployed on Heroku.

🌍 Land Cover Classification ⚠️ Anomaly Detection 🔄 Change Detection 🌲 Tree Crown Segmentation 📡 LiDAR Forest Inventory
🌍
Land Cover Classification
Upload a satellite image and the model predicts which of 10 land cover types it is: Forest, Residential, Highway, Industrial, Annual Crop, Pasture, Permanent Crop, Herbaceous Vegetation, River, or Sea/Lake. ResNet-50 fine-tuned on 27,000 Sentinel-2 patches — F1 = 0.99.

LiDAR Forest Inventory
Upload a LiDAR point cloud (.LAS/.LAZ). Builds a Canopy Height Model (CHM) and uses watershed segmentation to isolate individual trees. Returns canopy height, cover fraction, stem density per hectare, and per-tree metrics.
